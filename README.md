# Decision Replay Web 🚀

Welcome to the **Decision Replay Web** repository! This project contains web development files including HTML templates, PHP backend insertion scripts, DOM manipulation demos, and asset media[cite: 1].

## 📁 Repository Structure

Based on the repository contents[cite: 1]:

- **`index.html`** - The primary landing page / main interface of the application[cite: 1].
- **`contact.html`** - Contact form and user connection page[cite: 1].
- **`dom.html`** - Interactive DOM manipulation script/page[cite: 1].
