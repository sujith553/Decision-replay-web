Welcome to Task Decision System

The Task Decision System is designed to help users decide which task to perform first. It improves decision-making by organizing tasks based on priority and importance.

This system helps users save time, reduce confusion, and increase productivity by focusing on the most important tasks.

Why this project?

This project focuses on helping users make better decisions about their daily tasks. Many people struggle with choosing which task to do first.

This system provides a structured way to prioritize tasks based on urgency and importance, improving time management and efficiency.

Project Objectives

• Help users decide which task to perform first

• Classify tasks based on priority

• Improve productivity and time management

• Provide simple and effective task tracking
