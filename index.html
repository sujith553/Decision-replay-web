Welcome to Task Route System

The Task Route System is a simple web-based project designed to help users organize, manage, and review their daily tasks in an easy way.

Users can create tasks, track their progress, and mark them as completed. This system helps improve productivity and time management skills.

This website demonstrates basic web development concepts like HTML structure, navigation between multiple pages, and content organization.

Why this project?

This project is useful for students and beginners who want to understand how multi-page websites work. It shows how different pages are connected using hyperlinks and how information can be displayed clearly.

It can also be extended in the future by adding features like login system, task deadlines, reminders, and database storage.

Project Objectives

• Create a multi-page website

• Implement navigation using links

• Display tasks and their status

• Practice basic HTML design
